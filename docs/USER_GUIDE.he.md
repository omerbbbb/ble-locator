# BLE Locator — BLE Indoor Positioning System (v3.2)

מערכת מיקום פנימי מבוססת BLE. מזהה מכשירי Bluetooth בסביבה, מאפשר לבחור עוגנים, ומחשב את המיקום שלך בחדר בזמן אמת.

## הפעלה

**לחיצה כפולה על `BLE Locator` בשולחן העבודה.** זו אפליקציה עצמאית (standalone)
שמכילה את הכל — אפשר גם להזיז אותה לכל מקום או להעתיק למק אחר.

בפעם הראשונה macOS יבקש הרשאת **Bluetooth** — אשר אותה. אם לא קופץ, לך ל:
System Settings → Privacy & Security → Bluetooth → הפעל ל-"BLE Locator".

## איך משתמשים

1. הפעל — בפאנל הימני תראה את כל מכשירי ה-BLE בסביבה. הצבע = עוצמת אות:
   🟢 ירוק=חזק/קרוב, 🟠 כתום=בינוני, 🔴 אדום=חלש/רחוק. ⚓ = עוגן.
   "Unnamed" = מכשיר שלא משדר שם (נפוץ בטלפונים/שעונים מטעמי פרטיות).
2. הגדר **לפחות 3 עוגנים**: לחץ פעמיים על מכשיר, והזן:
   - **X, Y** — מיקום העוגן בחדר במטרים.
   - **Tx Power** — ה-RSSI הנמדד במרחק מטר אחד מהמכשיר (עמוד מטר ממנו וקרא את הערך).
   - **n** — מקדם דעיכה (2.5 = חדר רגיל).
3. אחרי 3 עוגנים — הנקודה הכחולה **"You"** תופיע על המפה ותזוז כשתזוז.
4. לחיצה ימנית על המפה → שינוי מידות החדר.

שתי תצוגות (טאבים מעל המפה):
- **Position Map** — טריאנגולציה: המיקום שלך כנקודה על מפת החדר.
- **Distance Radar** — אתה במרכז, וכל מכשיר כטבעת ברדיוס = המרחק המשוער אליו
  (אותה החלקה, בלי טריאנגולציה). שימושי לכיול ולראות את המרחק לכל מכשיר בנפרד.
  - **זום**: גלגלת העכבר או כפתורי ＋ ／ − ／ ⟳ — כדי להפריד בין טבעות קרובות.
  - **מיקום עוגן בגרירה**: גרור טבעת/מכשיר סביב המעגל (snap למעגל — המרחק נשמר,
    אתה בוחר כיוון). שחרור קובע את המכשיר כעוגן בכיוון הזה. הקואורדינטות נקבעות
    יחסית למיקומך (מרכז החדר ברגע הכיול).

הכיול נשמר ב-`~/Library/Application Support/BLE Locator/calibration.json`.

## מדידה מבוקרת (Start / Stop)

לפני Start האפליקציה **לא אוגרת/ממצעת** — אבל היא כן מציגה **תצוגה חיה רגעית** של
המרחק לכל מכשיר (מחושב מחדש כל שנייה מהאות הנוכחי, בלי היסטוריה). זה מאפשר לראות מה
סביבך לפני שמתחילים.

בלחיצה על **▶ Start Measurement** מתחילה **מדידה מצטברת ומדויקת** — כל הפילטרים
מתאפסים ומתחילים לצבור; עמוד במקום כמה שניות (~15-20ש') עד שהמרחק/המיקום מתייצב, ואז
**■ Stop** מקפיא את התוצאה. כל Start = איסוף חדש מאפס. "Reset" מחזיר למצב סרק ומנקה בחירה.

> הערה: עם **אנטנה אחת** של המק מודדים **מרחק** בלבד באמינות. ה-X/Y הדו-ממדי על המפה
> מוסק מגאומטריית העוגנים — תן אמון במרחק יותר מאשר בנקודה המדויקת.

- **מרחק לכל מכשיר** — בפאנל הימני מופיע מרחק משוער ליד כל מכשיר, לא רק עוגנים.
- **UUID** — רחף עם העכבר מעל מכשיר (בפאנל או ברדאר) כדי לראות את ה-UUID המלא שלו.
- **פוקוס ברדאר** — בחר מכשיר (לחיצה) כדי להדגיש אותו בכחול בולט; כפתור **◎**
  מציג **רק** את המכשיר הנבחר ("לראות רק את המרחק שלו"). הבחירה מסונכרנת בין הפאנל לרדאר.
- **סינון** — סליידר "Hide weaker than X dBm" מסתיר מכשירים חלשים/רחוקים; כפתורי
  All/BLE/WiFi מסננים לפי סוג.

## למה אני רואה כל כך הרבה מכשירים? (הד מול רנדומיזציה)

שתי תופעות נפרדות, ולא לבלבל ביניהן:

- **הד (multipath)** — הגל של מכשיר אמיתי מגיע גם ישירות וגם אחרי שהוא מקפיץ מקירות.
  העותקים מתחברים באנטנה וגורמים ל-RSSI של **אותו מכשיר** לקפוץ עד 10–20 dB. זה
  **מעוות את המרחק** של מכשיר קיים — הוא **לא** יוצר מכשירים חדשים. מכשירים כאלה
  מסומנים ב-〰️echo כשהשונות גבוהה.
- **ריבוי מכשירים** — נובע מ**רנדומיזציית כתובות** (אייפון/אנדרואיד מחליפים כתובת BLE
  כל ~15 דקות, אז אותו טלפון מופיע כמה פעמים) + מכשירי שכנים אמיתיים. הפתרון: להעלות
  את סליידר ה-RSSI כדי להסתיר את הרחוקים, ולבחור ידנית את המכשיר שמעניין אותך.

## בנייה מהמקור

```bash
cd ~/ble-locator
./build_app.sh          # בונה אפליקציה עצמאית → ~/Desktop/BLE Locator.app
```

להרצה מהמקור בלי בנייה (לפיתוח):
```bash
./run.sh                # = .venv/bin/python main.py
```

## מבנה — ארכיטקטורת שכבות

הקוד מחולק ל-4 שכבות + תשתיות. **המדריך המלא: [ארכיטקטורה.md](ארכיטקטורה.md)** (בעברית, כולל תרשימי זרימה ו"איך לקרוא את הקוד").

| שכבה | תיקייה | תפקיד |
|------|--------|-------|
| 📡 סורקים | `sensor/` | קליטת אותות (BLE / Mock / WiFi) |
| 🔧 עיבוד | `filtering/` | סינון רעש (Kalman / אחר) |
| 📐 מנוע | `engine/` | חישוב מיקום (טריאנגולציה / EKF) |
| 📋 מעקב | `traceability/` | תצפית ולוג אירועים |
| 📜 חוזים | `core/` | interfaces + DTOs + events |
| 💾 שמירה | `storage/` | JSON / SQLite / ענן |
| 🧠 תיאום | `services/` | "המוח" — מחשב מיקום |
| 🖼️ תצוגה | `ui/` | חלון PyQt6: מפה, רדאר, רשימה, גרף |

כל שכבה ניתנת להחלפה דרך interfaces — ראה `core/interfaces.py`.

`ble_locator.spec` / `build_app.sh` — בניית האפליקציה העצמאית (PyInstaller).
`engine/fingerprint.py`, `engine/particle_filter.py`, `sensor/wifi_scanner.py` — שמורים ל-v2/v3.

## התקנה ופיתוח

נבנה ונבדק על **Python 3.12** (חשוב — Python 3.14 מפיל את PyQt6).

```bash
git clone <repo-url> && cd ble-locator
make setup          # יוצר venv, מתקין תלויות
make test           # מריץ 57 טסטים
make run            # מפעיל את האפליקציה
```

טסטים לפי חבילה:
```bash
make test-engine     # engine/ בלבד
make test-filtering  # filtering/ בלבד
make test-services   # services/ בלבד
```

בנייה לאפליקציה עצמאית:
```bash
make build           # → dist/BLE Locator.app
```
